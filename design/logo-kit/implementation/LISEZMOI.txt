LOGO CLOISON : INTÉGRATION SITE
================================

Le meilleur format pour le web n'est PAS une image : le logo est du texte
(Archivo Black) + une barre CSS. En HTML/CSS il est vectoriel, net à toute
taille, léger (0 Ko d'image) et sa couleur s'adapte au fond.

1. cloison-logo.html
   Snippet copier-coller : la police à charger, la classe .cloison-logo
   et ses variantes (--inverse pour fond sombre, --blanc pour fond cobalt).
   La taille se règle uniquement avec font-size.

2. cloison-favicon.svg
   Favicon vectoriel (barre jaune sur carré cobalt : 100 % formes, aucune
   police requise). À déclarer :
   <link rel="icon" type="image/svg+xml" href="/cloison-favicon.svg">

3. Les PNG ×3 (dossier parent) servent pour les réseaux sociaux, l'image
   OG et partout où le HTML n'est pas possible (emails, presse).
